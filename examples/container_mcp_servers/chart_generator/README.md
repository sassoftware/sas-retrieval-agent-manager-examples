## Chart Generator Template

This README.md documents how to setup the SAS RAM charts MCP container
for use in RAM. It uses the MCP container found here: <TODO: link to pkgs in github>

This MCP container was forked from the MCP Server chart container(https://github.com/antvis/mcp-server-chart) and modified to return base64 encoded images as the tool output, rather than
hosting the generate images in an external URL.

IMPORTANT: To view the images generated by this tool server, you will need to use an agent
code template that renders the base64 images. See the [image render agent](../../agents/image_render_agent/) example for how to
create a template that does this.
