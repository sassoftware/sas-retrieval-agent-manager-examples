# Remote MCP Server

A Remote MCP Server is a built-in RAM catalog template that connects directly to an existing, externally hosted MCP server over HTTP. No custom code or container image is required — you just provide the server's URL and select a transport (for example, Streamable HTTP).

See [exa_web_search_mcp_server](/examples/catalog_mcp_servers/remote_mcp_server/exa_web_search_mcp_server/) for a worked example.
