# Text Summarizer Skill

Use this skill when the user asks to summarize, condense, or generate key takeaways from documents, articles, meeting transcripts, or reports.

## Instructions

1. Read the provided text completely before generating the summary.
2. Structure the output into three standardized sections:
   - **Executive Summary**: A two to three sentence high-level overview.
   - **Key Takeaways**: Three to five bullet points covering the most critical decisions, metrics, or announcements.
   - **Action Items / Next Steps**: A bulleted list of any required follow-ups, owners, or deadlines mentioned in the text. If none exist, state "None specified".
3. Maintain an objective, neutral tone and do not introduce outside facts.
